# Round Starts In 3 2 1

A lightweight Trackmania Openplanet plugin project for a clear round-start countdown.

By default, each detected pre-start window is normalized to a clear `3 -> 0` scale; those values are countdown steps rather than literal seconds. A setting can switch the overlay back to the real remaining time in seconds.
